<h1 align="center">Rusticle</h1>
<p align="center">High-performance Rust library for numerical computing, built with power and simplicity.</p>

## Installation

Add `rusticle` to your `Cargo.toml`:
```toml
[dependencies]
rusticle = "1.0.0" 
```

Or simple run this in your terminal
```bash
cargo add rusticle
```

## Modules

| Module | Description | Key Features |
|--------|-------------|--------------|
| **Complex** | Complex number arithmetic | • Basic operations (+, -, *, /) <br> • Conjugate and norm calculations <br> • Display formatting (a+bi) <br> • Generic over numeric types |
| **Vector** | Mathematical vectors | • Dot product and norm calculations <br> • Vector addition and subtraction <br> • Scaling and normalization <br> • Tensor product operations <br> • Indexing support |
| **Matrix** | Matrix operations | • Matrix multiplication <br> • Transpose operations <br> • Determinant calculation <br> • Element access and manipulation <br> • Various matrix constructors |
